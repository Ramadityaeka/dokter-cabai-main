# Dokter Cabai

Singkat: Kumpulan Jupyter Notebook untuk analisis dan pemodelan kesehatan tanaman cabai.

Demo (Streamlit): https://klasifikasi-daun-cabai.streamlit.app

Quick start:
1. Clone: git clone https://github.com/Ramadityaeka/dokter-cabai-main.git
2. Buat virtualenv/conda dan install dependensi minimal:
   pip install jupyterlab pandas numpy matplotlib scikit-learn streamlit
3. Jalankan notebook atau buka demo Streamlit di link di atas.
